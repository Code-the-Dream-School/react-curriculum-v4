## Weekly Exercises

The weekly exercises use the following repo: [Code-the-Dream-School/react-curriculum-v4-exercises: Exercises for React students](https://github.com/Code-the-Dream-School/react-curriculum-v4-exercises). Be sure to look over the [README](https://github.com/Code-the-Dream-School/react-curriculum-v4-exercises/blob/main/README.md) prior to forking the repo.

Inside the `/src/exercises` directory are weekly folders that each contain an `instructions.md` file and any necessary exercise files. The instructions introduce a scenario and provides several tasks or challenges based on the week's material.  The Lesson 1 Exercises Instructions can be found [here](https://github.com/Code-the-Dream-School/react-curriculum-v4-exercises/blob/main/src/exercises/lesson-01/instructions.md).
