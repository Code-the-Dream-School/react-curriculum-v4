### What You'll Get Out of this Course

You will learn React, a popular library for building interactive user interfaces. Through weekly assignments, you will build a [todo list](https://en.wikipedia.org/wiki/Time_management#Implementation_of_goals) app, practice what you learn with exercises, reflect on skills that support your growth as a developer, and check your understanding with quizzes.

This first lesson will orient you to the course structure and the materials you will use for lessons, exercises, and assignments.

### Course Structure

#### Curriculum Outline

The Intro to React v4 course is structured as 11 progressive weekly lessons. Each lesson builds upon concepts from previous weeks, making it essential to complete the course sequentially without skipping ahead or missing content.

- **Lessons 1-6** basics of React
- **Lesson 7**  working with data fetched from an API
- **Lesson 8 and 9** advanced hooks
- **Lesson 10** use React-Router to improve web-based navigation
- **Lesson 11** progressing as a React Developer

The materials for the course is further broken down into a full list of topics covered each week. Every section is titled with their topics so that they double as useful search terms when looking for external resources.

- **Lesson-01:** Intro to React, App Installation, and Working with Vite
- **Lesson-02:** ReactDOM, Components, JSX, and Troubleshooting
- **Lesson-03:** Component Lifecycle, Basic Hooks, State, and Props
- **Lesson-04:** Hooks Continued, Events and Handlers
- **Lesson-05:** Local State and Controlled Components, and Forms
- **Lesson-06:** Re-usable Components, Project Organization, and Refactoring
- **Lesson-07:** Data Fetching and UI Update Strategies
- **Lesson-08:** Advanced Hooks: useCallback and useMemo, Optimizing a React App, and API-based Sort/Search
- **Lesson-09:** Advanced State, useReducer, and useContext
- **Lesson-10:** React Router
- **Lesson-11:** Polishing an App for Your Portfolio, App and Data Security, and Deploying a React App

Each weekly lesson concludes with a dedicated section that gathers all referenced resources and links in one place, along with additional helpful materials. This makes it easier to quickly find and access useful information without searching through the entire lesson.

#### 4. Weekly Submissions

On most weeks you will have four tasks to complete:

1. A graded weekly assignment: todo list app PR (use the `URL` field in the submission form)
2. A ungraded weekly exercise PR (use the `URL2` field in the submission form)
3. A ungraded mindset response
4. A weekly quiz

The assignment, exercise, and mindset response all go together in you weekly assignment submission form. The quiz is completed in [AIRHub](https://ai-review.codethedream.org/).

##### Weekly Assignments: Todo List Project

For our assignments, you will be creating a todo app in a new GitHub repo. A typical todo app helps you capture tasks, prioritize what to do, and keep track of what is complete. You will build these features over the course of the weekly assignments. Later, you will connect your app to an API so it can retrieve todos and send changes, such as adding or updating a task, to a server. This lets your todo list persist after you close the app out.

The first week's lesson will cover how to set this up and work with git version control. Each week's assignment instructions give you a mix of detailed steps to follow, and some tasks to figure out on your own. This mix of guided instruction and independent problem-solving keeps the course challenging and interesting. Developers working in production environments are expected to research and problem-solve as part of their job. Some tasks that you will encounter in this course may be challenging, but they're designed to be manageable for someone learning React.

Once your assignment work is complete, you'll open a PR with the changes. That PR link should be added to the submission form. Once submitted (don't forget about the weekly exercise and the mindset response!), CTD's AI reviewer, AIRHub will examine the todo list PR to approve or recommend changes. Any changes will be communicated back through the AirHub interface and via an Airtable email alert. You'll be expected to make any requested changes before starting the next lesson. If you have questions about the review or need any clarifications, use Slack to talk with your reviewer or another one of the cohort volunteer mentors. They are there to help you out!

##### Weekly Exercises

The weekly exercises use the following repo:[Code-the-Dream-School/react-curriculum-v4-exercises: Exercises for React students](https://github.com/Code-the-Dream-School/react-curriculum-v4-exercises). Inside the `/src/exercises` directory are weekly folders that each contain an `instructions.md` file and any necessary exercise files. ##### Mindset Response

Each week, you will write a short, essay-style response to a prompt about a soft skill or another topic that supports your growth as a developer. This ungraded reflection is a chance to consider how the idea applies to you and how you might incorporate it into your approach to learning and work.

##### Weekly Quiz

Each week, complete a quiz in AIRHub based on that week's materials. Quizzes combine multiple-choice questions with an occasional coding component. Quizzes can be accessed here: [AIRHub](https://ai-review.codethedream.org/). You can find your quizzes by clicking on "Cohorts" in the left panel, then selecting the week's lesson and clicking "Start Quiz".

### Course Requirements

#### 1. Computer Requirements

You can complete this course on a desktop or laptop running a currently supported version of Windows, macOS or Linux. You do not need specialized hardware but you will need a reliable internet connection, a modern web browser, and permission to install software.

You will use a terminal to run commands: Terminal on macOS, or PowerShell or Windows Terminal on Windows. You will also need [Node.js](https://nodejs.org/en/download), which includes npm, and [Git](https://git-scm.com/downloads). Lesson 1 walks you through installing the tools and setting up a Vite project. Check the [Vite guide](https://vite.dev/guide/) for supported Node.js versions, since requirements can change.

#### 2. Code Editor

[Visual Studio Code (VS Code)](https://code.visualstudio.com/) is a free editor that works on both Windows and macOS and is recommended for this course. You will use it to open your project folder, create and edit JavaScript, JSX, HTML, and CSS files, and work with the integrated terminal. Other code editors are also fine if they support JavaScript and JSX; you can run commands in your computer's terminal separately.

#### 3. Recommended Prior Knowledge

No prior React experience is necessary but some familiarity with the following will help you get started:

- **JavaScript:** variables, functions, arrays, and objects
- **HTML and CSS:** common HTML elements and basic CSS selectors and properties
- **Git and GitHub:** what a repository and commit are, how to push changes to GitHub, and how to open a pull request

The first week's materials introduce the project setup and Git workflow. Review those materials and ask your instructor or mentor for help if any of these tools or concepts are new to you.

Each week builds on the previous, ensuring a structured and comprehensive learning experience. The materials are crafted to encourage both practical coding and critical thinking, preparing you for real-world development.
